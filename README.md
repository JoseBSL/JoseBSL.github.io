# Jose Lanuza — personal scientific website

A starter Quarto website with a hybrid personal/academic design.

## Run locally

1. Install Quarto: https://quarto.org/docs/get-started/
2. Open this folder in RStudio (or a terminal).
3. Run `quarto preview` in the terminal, or `quarto render` to generate `_site/`.
4. To publish, follow https://quarto.org/docs/publishing/github-pages.html

## Before publishing

- Replace the portrait placeholder in `index.qmd` with your photo.
- Replace the generic platform links with your personal Google Scholar, Bluesky, LinkedIn, GitHub and ORCID URLs.
- Add verified publication citations and DOI links.
- Review the draft biography and research descriptions.
- Update the CV link and affiliation when appropriate.
